# وطن نبدع له 96

المعرض الوطني الرقمي لابتدائية خالد بن الوليد – نجران.

## البنية
- Frontend: React + Vite + Tailwind
- Backend: Supabase Edge Function `watan-nobde3-96-api`
- Database/Storage: Supabase project `shifrat-watan-96` بعزل جداول/bucket خاصة بالمشروع
- Production target: Cloudflare Pages

## Cloudflare Pages
- Root directory: `projects/watan-nobde3-96`
- Build command: `npm install && npm run build`
- Output directory: `dist`
- Production branch: `watan-nobde3-96`
