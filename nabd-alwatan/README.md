# نبض الوطن
مبادرة تفاعلية لإضاءة حدود المملكة والنخلة مع مشاركات الوفاء.
- واجهة RTL بخط Cairo، إحصاءات ومدن وجدار رسائل ولوحة صدارة وبطاقات مشاركة.
- خادم Node.js مستقل (بدون حزم npm خارجية) وتخزين على القرص الدائم.
- مدير منصة واحد فقط؛ رسائل الزوار المخصصة لا تنشر قبل موافقة المدير.
- يتطلب إعداد ADMIN_PASSWORD كمتغير بيئة سري لا يقل عن 12 رمزًا.
- نقطة الصحة: GET /api/health.
- نشر Render: راجع DEPLOY_RENDER.md و render.yaml.
